#Hand off the whole taskNEW

reins do gives a browsing goal to Jev, TypeSafe's action model. Jev picks each click in about 0.2 s. Your agent supplies the values and checks the result.

claude — ~/app
$ reins do 'find the package and open it' --fill query=zod
done in 3.5s · 3 steps · 4 jev calls · 16k tokens · self-check 0.94
  1 click  "Search packages"
  2 type   "Search packages" ← query
  3 click  "zod"
now: https://www.npmjs.com/package/zod — "zod - npm"
next: reins snapshot   # verify before trusting DONE
$ reins snapshot
e2: link "zod"
e5: button "Copy install command"
$
